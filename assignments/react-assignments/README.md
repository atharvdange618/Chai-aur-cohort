# FreeAPI Projects

A collection of 8 frontend projects built with React, TypeScript, and Tailwind CSS using the FreeAPI public APIs.

## Projects

| #   | Project                          | Description                                                                |
| --- | -------------------------------- | -------------------------------------------------------------------------- |
| 1   | [Authentication App](/project/1) | User registration, login, logout, and profile management                   |
| 2   | [YouTube Videos UI](/project/2)  | YouTube-style video listing with thumbnails, duration, views               |
| 3   | [Product Listing](/project/3)    | E-commerce product grid with prices, ratings, discounts                    |
| 4   | [Quotes Listing](/project/4)     | Quote gallery with author attribution and tags                             |
| 5   | [Jokes Viewer](/project/5)       | Random jokes with category filtering                                       |
| 6   | [Random Cat Viewer](/project/6)  | Cat facts with images, traits, and favorites                               |
| 7   | [Meals Listing](/project/7)      | Recipe cards with detailed instructions and YouTube links                  |
| 8   | [Random Users UI](/project/8)    | User profile cards with location and contact details                       |
| 9   | [Stopwatch & Timer](/project/9)  | Interactive stopwatch with lap recording and countdown timer               |
| 10  | [Tic Tac Toe](/project/10)       | Classic 3x3 game with local PvP and AI modes, scoreboard, and retro sounds |

## Tech Stack

- **React 19** with TypeScript
- **Tailwind CSS v4** for styling
- **shadcn/ui** component patterns
- **React Router** for navigation
- **Vite** for development and building

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
